📖 閱讀消化分身

痛點：每天被資訊轟炸，存了一大堆「稍後再看」但永遠不看。

丟連結 → AI 幫你讀 → 產出摘要+重點+啟發 → 存進你的知識庫。

⏱ 人類45分鐘 → 分身30秒

🔍 Google Drive 分身

痛點：「我知道我有這份資料，但我找不到。」高階知識工作者最大痛點。

用自然語言搜尋：「幫我找那篇去年的提案」「這三份有什麼差異？」

⏱ 人類找10分鐘 → 分身10秒

🎤 語音 → 行動

痛點：說得比寫得好，但語音靈感往往流失。

錄30秒語音 → 提取待辦、知識筆記、行事曆事件草稿 → 你確認後寫入。

⏱ 靈感不再流失
